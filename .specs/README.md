# Especificações de mudança

Cada mudança descrita nesta pasta deve incluir:

- **Contexto:** problema, motivação e informações relevantes.
- **Tarefa:** comportamento ou resultado solicitado, com escopo claro.
- **Regras:** restrições de arquitetura, implementação, compatibilidade e operação.
- **Definição de pronto:** critérios verificáveis para considerar a mudança concluída.

Esta pasta não entra automaticamente no contexto de trabalho. O agente só deve ler uma especificação daqui quando receber instrução explícita para fazê-lo, com o arquivo ou a tarefa identificados.
